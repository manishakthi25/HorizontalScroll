#Horizontal_Scroll.class

## Overview
This Selenium Java project demonstrates how to perform horizontal scrolling on a webpage using JavaScriptExecutor.
It is useful for testing:

Horizontally scrollable sections
Hidden web elements
Dynamic web content
Responsive UI components

# Tech Stack
Java
Selenium WebDriver
ChromeDriver
Eclipse / IntelliJ IDEA

Project Structure

```bash
Horizontal_Scroll.class
```

# Features
Perform horizontal scrolling using Selenium
Uses JavaScriptExecutor
Automates hidden content validation
Beginner-friendly Selenium example


# Sample Code
```java
JavascriptExecutor js = (JavascriptExecutor) driver;
js.executeScript("window.scrollBy(500,0)");
```

# How to Run
1. Install Java and Selenium
2. Configure ChromeDriver
3. Open project in Eclipse or IntelliJ
4. Run `Horizontal_Scroll.class`


# Learning Outcome
After completing this project, you will understand:

Horizontal scrolling automation
JavaScriptExecutor in Selenium
Handling scrollable web elements
